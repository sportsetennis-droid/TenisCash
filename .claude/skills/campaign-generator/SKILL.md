# Campaign Generator

## Workflow

1. Define objetivo comercial (giro / receita / lançamento / lealdade)
2. Define cliente-alvo (segmento)
3. Define produto/oferta
4. Cria gancho principal
5. Cria direção visual
6. Versões por canal:
   - Feed Instagram
   - Story Instagram
   - WhatsApp
   - Áudio
   - Sinalização in-store
   - Script vendedor
7. Define KPI e plano de benchmark

## Output

```
Nome da campanha
Objetivo
Oferta
Gancho central
Feed
Story
WhatsApp
Áudio
Sinalização in-store
Script vendedor
KPI
Brief safety-agent: PENDENTE
```
