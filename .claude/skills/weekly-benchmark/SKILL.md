# Weekly Benchmark

## Workflow

Comparar:
- Campanhas A vs B
- Lojas (Bessa vs Tambaú vs RB vs Tambiá)
- Vendedores (top vs bottom)
- Produtos (categorias)
- Canais (físico vs ecommerce vs WhatsApp)
- Ofertas

## Output

```
Vencedor: [item + KPI superior]
Por que venceu: [análise causal]
Fraqueza do perdedor: [diagnóstico]
Lição operacional: [generalização]
Próximo teste: [hipótese a validar]
Nova regra pro playbook: [se confirmada]
```

## Dia da semana

Toda segunda 09h, com dados da semana anterior. Saída direto pro briefing matinal.
