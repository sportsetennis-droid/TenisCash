# WhatsApp Sales Playbook

## Estrutura da mensagem

1. Gancho pessoal
2. Produto/benefício
3. Oferta ou razão pra agir
4. UMA pergunta/ação clara

**Sem parágrafos longos.**

## Output

```
Segmento: [...]
Primeira mensagem: [...]
Follow-up 2h: [...]
Follow-up 24h: [...]
Respostas pra objeções: [...]
CRM tag: [...]
```

## Regras

- 1 mensagem = 1 objetivo
- Use produto + benefício + condição + ação
- Nunca robotizado
- Sempre próxima ação clara
- Máx 1 imagem por mensagem de campanha
- Áudio só pra relacionamento

## Aprovação obrigatória

Toda mensagem antes de envio: `safety-agent` revisa.
