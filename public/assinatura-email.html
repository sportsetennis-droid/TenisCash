— Daqui pra baixo é o que aparece na sua assinatura —
Como instalar no Gmail: Configurações ⚙ → Ver todas as configurações → aba Geral → role até Assinatura → "+ Criar" → cole o HTML no campo (em rich text mode) → Em "PADRÕES DA ASSINATURA" selecione a nova → Salvar.

Outlook web: Configurações ⚙ → "Conta" → "Assinaturas" → cole o HTML.

Apple Mail (Mac): Mail → Preferências → Assinaturas → arrasta o .html baixado ou cola o HTML.
