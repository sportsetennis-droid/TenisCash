# APEX SOCIAL — Feed, Clubes, Desafios

## Feed

```typescript
interface FeedPost {
  user: UserProfile;
  activity: Activity;
  photos: Photo[];
  storyCard?: AutoGeneratedStoryCard;  // gerada pelo backend
  kudos: KudosReaction[];
  comments: Comment[];
  visibility: 'public' | 'followers' | 'clubs' | 'private';
}
```

### Reactions
- 👏 kudos (default)
- 🔥 fire
- ❤️ love
- ⚡ speed
- 😂 funny

Máximo 1 reação por usuário por post (pode trocar).

### Ranking do feed
- Não cronológico puro
- Mistura: recência + engajamento + relevância (clubes seguidos, amigos próximos)
- Atividades de **clubes que o usuário pertence** têm boost

## Clubes

| Tipo | Visibilidade | Quem entra |
|---|---|---|
| Public | Qualquer um vê | Qualquer um pede |
| Private | Só membros veem | Aprovação manual |
| Invite-only | Não aparece em busca | Por convite direto |

### Funcionalidades
- Feed do clube
- Ranking interno (distância semanal, etc.)
- Desafios próprios
- Eventos do clube
- Lista de membros

## Desafios

```typescript
interface Challenge {
  ruleType: 'distance' | 'time' | 'elevation' | 'streak' | 'social';
  ruleConfig: {
    targetValue?: number;
    targetSports?: SportType[];
    minActivitiesPerWeek?: number;
  };
  startsAt: Date;
  endsAt: Date;
  prizeType: 'badge' | 'premium_month' | 'merch' | 'nft';
  sponsorId?: string;     // branded challenges
  visibility: 'public' | 'club' | 'private';
}
```

### Tipos
- **Pessoal** — usuário cria pra si
- **Amigos** — convida 1-N pessoas
- **Clube** — todo o clube participa
- **Comunidade** — qualquer um entra
- **Branded** — patrocinado por marca

## Live tracking (segurança)

```
Atleta inicia atividade → cria LiveTrackingSession
                       ↓
Sistema gera token único
                       ↓
Atleta compartilha link: apex.app/live/{shareToken}
                       ↓
Familiares acompanham em tempo real
                       ↓
Token expira em X horas OU quando atividade termina
                       ↓
Atleta pode revogar antes (Pânico/Privacidade)
```

## Implementação

- WebSockets / SSE pra live tracking real-time
- Redis pra estado de live sessions (TTL automático)
- Postgres pra metadados + audit trail
