# Fontes das etiquetas

As faces 5 x 7 cm usam Roboto Slab, uma família gratuita do Google Fonts,
distribuída sob a licença SIL Open Font License (OFL). Os arquivos TTF ficam
versionados no projeto para que o PDF seja idêntico no servidor e na impressora.

Fonte: https://fonts.google.com/specimen/Roboto+Slab
